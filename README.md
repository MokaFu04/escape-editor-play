# 逃生剪辑师 · 在线试玩

[立即试玩](https://mokafu04.github.io/escape-editor-play/)

当前版本：**1.1.3**。通过排序、倒放、剪除、定格与复制镜头，让小橘安全离开。
包含 6 节独立新手教学、4 章 12 个正式关卡，四季原创像素美术；第五章预留，适合宽屏电脑浏览器。

点击「开始游戏」进入主线，或选择「新手教学」。点击素材下方的「正放 / 倒放」切换方向。
按 G 或点击 GM 可自由选关。潮水、坍塌、落石、枯枝和木箱片段决定片头障碍；剪除后恢复安全，放回后重新出现。
进度保存在当前浏览器；下载 index.html 后也可离线运行。

此仓库保存可公开访问的试玩成品；main 根目录由 GitHub Pages 自动发布。
release.json 记录版本与 HTML 的 SHA-256，Git 历史保留历次部署。
